Better Icons

The icons of VS Code's Material Icon Theme for the other mods. With it installed, Better Files shows a colour icon for every file and folder: a TypeScript file, a package.json, a .github folder and a src folder each look different.

Version 1.0.0Needs: Nothing extraSource on GitHub

Quick start

  1. Install with the prompt below, beside Better Files.
  2. Open the Files panel. Every file and folder has its Material icon, and an open folder shows its open icon.

Install

Read ~/.config/herdr-app/AGENTS.md, then add this mod: https://github.com/munza/herdr-mods/tree/main/better-icons

The agent follows RECIPE.md. It isn't a panel, so it needs no place in a layout: other mods read its icons by path. It runs no programs, reaches no network, and reads only its own folder.

Install by hand

To install by hand from a clone of the repository, sync.sh copies mods/better-icons/ into Herdr's mods folder:

./better-icons/sync.sh

Use

  • Optional: a mod that uses it keeps its own plain icons when it isn't installed. Today that's Better Files: its tree and its file tab's title row.
  • Picked the way VS Code picks them: a rule for a path, such as .github/workflows, beats a name, a name beats an extension, and the longest extension wins, so app.spec.ts gets the test icon and app.ts the TypeScript one.
  • Light themes get the theme's light icons for the 236 names it has them for.
  • Shown in a layout anyway, it lists a few sample names with their icons.

Limits: 1,184 icons from Material Icon Theme 5.40.0, about 5 MB. A mod reads the table when it starts, so after an update reopen its panel or restart Herdr. A symlinked mod folder loads code but not icons, so install by copying.

Settings

Better Icons has no settings.

Update

Copy mods/better-icons/ into Herdr again, then reopen the panels that use it.

For developers

To use the icons in your mod, copy mods/better-icons/file-icons.js into it, unchanged, since a mod can't import from another's folder. Read the table once, and draw with image(), since svg() would tint a colour icon one colour:

const table = await loadFileIcons();          // null without Better Icons
const picture = fileIcon(table, "src/app.ts", { dir: false, open: false, light: settings().dark === false });
picture ? image(picture).size(14) : myOwnIcon

To move to another release of the theme, change VERSION in generate.mjs and run it on the unpacked npm package. It reads only the package's JSON and SVG files, and the tests then check every named icon is there.

npm pack material-icon-theme@<version> && tar xzf material-icon-theme-<version>.tgz
node generate.mjs package
node --test tests/*.test.cjs
./sync.sh
herdr-app check "$HOME/.config/herdr-app/mods/better-icons"
