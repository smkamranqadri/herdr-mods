Estro

Estro

A layout built from these mods, for directing agents: every space and agent on the left, the session you're with in the middle, and a panel on the right for checking their work. Estro is Esperanto for the one in charge.

Needs: What its mods needSource on GitHub

Quick start

  1. Paste the prompt below into your Herdr agent. It installs the layout and every mod, and switches to it.
  2. Pick a panel from the toolbar at the top right: Files, Changes, PRs or Issues.
  3. Open Mod settings in the sidebar footer to change any mod's settings.

Install

Read ~/.config/herdr-app/AGENTS.md, then add this layout: https://github.com/munza/herdr-mods/tree/main/estro

The agent copies layouts/estro.json, then adds all seven mods with each mod's own prompt, telling you what each can do as it goes. It skips each mod's layout step, because Estro already places it, and updates any mod you already have. It never overwrites a mod or a layout already there under the same name. Last, it runs herdr-app check on each mod and switches to the layout.

Branch PR needs gh and Branch Issue a Linear API key; both need Go 1.23+ to build their helper. Tell the agent to leave out any of them, and it drops that mod's button and block.

Use

  • Sidebar, 268px: Herdr's brand block, then Better Sidebar's spaces and agents in one block under Spaces and Agents tabs, with each space's tabs beneath it, and its one-line footer with Settings, Mod settings (Better Config) and Add machine.
  • Work area: Better Tabs at the top with Better Sidebar's panel toggle at the far right, the active tab's terminals in the middle, and Herdr's status bar at the bottom.
  • The panel, 368px: one view at a time, picked from the Better Tabs toolbar: Files, Changes, PRs and Issues. Each space remembers which panel it had open.

Update

Run the same prompt again: mods you already have are updated instead of installed again, and your existing estro layout is left alone.

For developers

estro/mods/ holds a one-line pointer per mod, not copies, so there is one copy of each mod in the repo. RECIPE.md is the brief: enough to build Estro from an empty folder. The toolbar buttons are panel actions with container: "panel" and stack: "panel-body".

node --test estro/tests/*.test.cjs
