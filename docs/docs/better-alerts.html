Better Alerts

System notifications on Linux: when an agent needs you, or finishes while you're looking elsewhere, your desktop says so, even with Herdr behind another window. Click the notification to open that agent.

Version 1.0.0Needs: Linux, notify-sendSource on GitHub

Quick start

  1. Install with the prompt below.
  2. Give an agent a task, then switch to another app. When it asks for permission or finishes, a notification comes up; click Open to go straight to it.

Install

Read ~/.config/herdr-app/AGENTS.md, then add this mod: https://github.com/munza/herdr-mods/tree/main/better-alerts

The agent follows RECIPE.md. Better Alerts draws nothing, so it runs as an empty floating block in a layout you own:

"floating": [
  { "id": "better-alerts", "content": { "mod": "better-alerts" },
    "edge": "bottom", "align": "end" }
]

It needs notify-send, from libnotify, and a notification daemon such as mako, dunst or GNOME's. It runs notify-send, and on a click herdr-app do agent.focus and, on Hyprland, hyprctl to bring Herdr forward. It reaches no network and reads only its own folder. On macOS and Windows it does nothing.

Install by hand

From a clone of the repository, sync.sh copies mods/better-alerts/ into Herdr's mods folder. Then add the floating block above to your layout.

./better-alerts/sync.sh

Use

  • Needs you: an agent asks for input or permission.
  • Finished: an agent that was working is done, and you weren't looking at it: Herdr was in the background, or another tab was shown.
  • Click a notification's Open action, and Herdr shows that agent and comes to the front.
  • The title names the agent, like Claude Code needs you, and the body says where it is, like lantern-app / Fix the login form.
  • Sub-agents stay quiet; their parent speaks for them. Agents already waiting when Herdr starts don't post. Herdr's own in-app toasts are unchanged.

Limits: Linux only. Only Hyprland gets the window brought forward on a click; elsewhere Herdr shows the agent but may stay behind other windows. It checks twice a second.

Settings

Better Config shows these with what each one does. By hand, add a settings block to the installed mods/better-alerts/mod.json with only what you change.

SettingDefaultWhat it does
alerts.blockedtrueA notification when an agent needs you.
alerts.donetrueA notification when an agent finishes while you aren't looking at it.

Update

Copy mods/better-alerts/ into Herdr again; Herdr reloads it. Your settings in the installed mod.json are replaced, and Better Config offers to restore them.

For developers

Every 500ms it compares each agent's status with the last look and posts through a detached shell, so exec answers at once and a click still works later. RECIPE.md has the details.

node --test better-alerts/tests/*.test.cjs
./better-alerts/sync.sh
herdr-app check "$HOME/.config/herdr-app/mods/better-alerts"
